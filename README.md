# Game_Snake_POO

Trabalho Final de POO
Implementação de um Jogo Simples

- Interface Principal (MainFramePanel extends JFrame)
- Paindel de Desenho (DrawPanel extends JPanel)
- Evento de Teclado ou Mouse (GameKeyHandler extends KeyAdapter)
- HUD (HUDPanel extends JPanel)

- Pelo menos 3 entidades (Herói, Inimigo, Ouro)
- Tem que desenhar (paint) pelo menos as 3 entidades (pode ser imagens também - gif, png, jpeg)
- Pelo menos duas entidades devem se mover
- Deve ter contagem de pontos, pelo menos

- Deve implementar Threads
- Deve trabalhar com List (ArrayList ou Vector)
- Deve ter herança (extends)
- Deve ter interface (implememts)
- Deve ter alguma forma de polimorfismo
- Deve ter alguma forma de colisão
- Deve ter sobrecarga (ou construtor ou método)
- Deve ter sobreescrita (polimorfismo)
